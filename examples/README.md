# Demo assets

`demo.cast` is adapted from [`asciinema/agg` at commit `e7b0e3b`](https://github.com/asciinema/agg/blob/e7b0e3bd597798734a86669d7118eef7799da2ab/demo.cast). The final `agg demo.cast demo.gif` sequence was replaced with `asg demo.cast demo.svg --window` and ASG's actual completion output.

`demo.svg` is generated by ASG with macOS-style window decorations. Starting at 0.1 seconds gives image renderers that do not play SVG animation a useful prompt instead of the recording's initial blank frame.

```bash
asg examples/demo.cast examples/demo.svg --window --from 0.1
```

The upstream recording and the derived demo SVG retain `asciinema/agg`'s GPL-3.0-or-later terms; a copy is included as [`LICENSE.GPL-3.0-or-later`](LICENSE.GPL-3.0-or-later). ASG source code outside these demo assets remains Apache-2.0.
